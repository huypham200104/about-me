📦 Ứng Dụng Quản Lý Kho

Dự Án Doanh Nghiệp (VPS) Android PDA Bảo Mật Nội Bộ
Xem Kinh Nghiệm VPS →

Giải pháp ứng dụng di động tác nghiệp kho bãi dành cho thiết bị cầm tay Android PDA công nghiệp. Hệ thống tập trung tối ưu hóa tốc độ xuất/nhập/kiểm kê hàng hóa, kết nối trực tiếp với súng quét mã Laser vật lý và giải quyết sự cố hiện trường theo thời gian thực.

  • ⚡
    Quét mã Laser phần cứng siêu tốc: Tích hợp súng quét Laser Android PDA qua Android Broadcast Intent, giảm hơn 80% thao tác quét thủ công, xử lý quét liên tục hàng trăm mã vạch pallet không độ trễ.
  • 📹
    Đàm thoại Audio/Video hiện trường: Tích hợp LiveKit WebRTC SFU và SignalR Hub duy trì cuộc gọi đa bên thời gian thực với độ trễ <500ms, hỗ trợ nhân viên kho xử lý tức thời các vấn đề pallet lỗi.
  • 🏛️
    Backend Clean Architecture & Auto-Merge: Xây dựng API Backend .NET 8 theo mô hình Clean Architecture xử lý đường ống tra cứu tập trung và thuật toán dồn pallet tự động; đồng bộ Web điều phối Angular Standalone.
  • 🚀
    Vận hành Zero-Downtime: Trực tiếp cấu hình và vận hành quy trình phát hành dịch vụ không gián đoạn trên cụm máy chủ Windows Server / IIS, bảo vệ an ninh mạng với Tailscale VPN và tường lửa 24/7.
React Native 0.86 React 19 Android PDA Intent LiveKit WebRTC SFU SignalR Hub .NET 8 Web API Angular Standalone Windows Server / IIS Tailscale VPN

📅 Ứng Dụng Quản Lý Lịch Họp

Dự Án Doanh Nghiệp (VPS) iOS & Android Bảo Mật Nội Bộ

Ứng dụng di động quản lý và điều phối lịch họp số, lịch công tác và phòng họp thông minh dành cho doanh nghiệp. Ứng dụng tập trung vào tính bảo mật dữ liệu cấp cao và tối ưu hóa quy trình đóng gói phân phối tự động.

  • 🛡️
    Xác thực tập trung OAuth 2.0 PKCE SSO: Triển khai quy trình đăng nhập bảo mật một lần SSO (Single Sign-On) theo chuẩn OAuth 2.0 với luồng Proof Key for Code Exchange (PKCE), đồng bộ quyền hạn người dùng tức thời.
  • 🔒
    Chống rò rỉ tài liệu mật (Anti-Screen Capture): Tích hợp cơ chế bảo mật hệ thống ngăn chặn hành vi chụp ảnh màn hình (Screenshot Blocking) và quay video màn hình trên cả iOS & Android để bảo vệ an toàn tài liệu họp bí mật.
  • ⚡
    Đồng bộ lịch & Nhắc việc thời gian thực: Tối ưu luồng dữ liệu thông báo đẩy và đồng bộ trạng thái phòng họp, lịch làm việc đa thiết bị mượt mà không xung đột giờ họp.
  • 🚀
    CI/CD tự động hóa lên Apple TestFlight: Thiết lập toàn diện đường ống tự động với Fastlane + GitHub Actions, rút ngắn chu kỳ build, ký số và phát hành lên Apple TestFlight từ 2 ngày xuống <20 phút.
