Nhà Phát Triển Ứng Dụng Di Động

Cross-platform

NailMatch (ShopNail)

Ứng dụng gợi ý mẫu nail nghệ thuật ứng dụng thị giác máy tính AI (MediaPipe + ResNet-18) với độ trễ <50ms qua pgvector HNSW. Tối ưu bộ nhớ đệm 3 tầng đạt chuẩn 120fps và triệt tiêu trùng lịch bằng PostgreSQL Exclusion Constraints.

Flutter FastAPI PostgreSQL Supabase pgvector

NewsWave Mobile

Ứng dụng đọc báo ngoại tuyến tức thì (Offline-first) với bộ nhớ cục bộ Hive. Áp dụng Clean Architecture 3 tầng, BLoC 9.0 và bộ kiểm thử tự động TDD toàn diện với 14 file test (~2.200 LOC) bao phủ Unit, BLoC và Widget test.

Flutter Clean Architecture BLoC 9.0 Hive TDD
▶ Google Play GitHub

Android

FG-Kho PDA Warehouse

Ứng dụng chuyên dụng cho máy cầm tay Android PDA (Honeywell, Zebra) trong quản lý kho bãi. Tích hợp súng quét Laser qua Broadcast Intent giảm 80% thao tác quét, đàm thoại video WebRTC LiveKit thời gian thực <500ms.

React Native 0.86 TypeScript LiveKit WebRTC SignalR PDA Scanner
